# コミットの分割

コミット分割は、ユーザーがステージ・コミットを明示し、差分の担当者と含めるパス・差分箇所が明確な時だけ行います。目的を一行で説明でき、可能なら単独で成立する単位を選びます。依存する変更を、動作しない中間コミットへ無理に分けません。

読み取り専用で状態、未ステージ・ステージ済み・未追跡の差分、直近の履歴、対象範囲、検証結果を確認します。担当者不明、機密情報の疑いがある差分、未承認のパス、差分と目的の不一致があれば停止します。

各単位について`git_guard`の事前確認とスナップショットを照合し、指定どおりのパス・差分箇所だけをステージします。補助スクリプトの`index-tree`で固定したツリーの差分を確認し、その`expected_index_tree`を渡して、既存コミットを修正しない通常のコミットを行います。前後でindex、作業ツリー、現在の参照、コミットのツリー、事後スナップショットを確認します。push、amend、rebase、reset、変更破棄は行いません。
